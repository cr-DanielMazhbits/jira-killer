# Jira Field Filler

Chrome extension that automatically completes ENG Jira tickets.

## Installation

1. Download and extract this repository
2. Open Chrome and go to `chrome://extensions/`
3. Enable **Developer mode** (top right)
4. Click **Load unpacked**
5. Select the extension folder

## What It Does

- Validates ticket is from **ENG project**
- Checks **Parent field** is filled
- Updates all required Jira fields
- Moves ticket to **Done** state

## Usage

1. Navigate to an ENG Jira ticket
2. Click the extension icon
3. Click **Complete Ticket**
4. Done! ✓

## Requirements

- ENG project tickets only (e.g., ENG-3153)
- Parent field must be filled before use
